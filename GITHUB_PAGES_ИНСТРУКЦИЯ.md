# 🎁 Загрузка коллажа на GitHub Pages

## 📋 Что нужно сделать

### Шаг 1️⃣: Создать аккаунт GitHub (если нет)
- Переди на [github.com](https://github.com)
- Нажми "Sign up"
- Заполни данные (email, пароль, username)
- Подтверди email

### Шаг 2️⃣: Создать новый репозиторий
1. Нажми "+" в правом верхнем углу
2. Выбери "New repository"
3. Назови репозиторий (например: `family-collage`)
4. Выбери "Public" (обязательно!)
5. Нажми "Create repository"

### Шаг 3️⃣: Загрузить файлы

**Вариант A (Самый простой - через веб)**
1. В репозитории нажми "Add file" → "Upload files"
2. Перетащи все эти файлы:
   - `index.html` ⭐ (главный файл)
   - папку `photos/` (28 фото)
   - `music.mp3`
   - папку `fonts/` (шрифты)
   - `og-image.jpg` (превью ссылки)
   - `apple-touch-icon.png` (иконка для iPhone)
   - `manifest.json`
   - `service-worker.js`
   - `icon-192.png`
   - `icon-512.png`
   - `icon-maskable.png`
   - `screenshot-540.png`
   - `screenshot-1080.png`
3. Нажми "Commit changes"

**Вариант B (Через Git - если знаешь)**
```bash
git clone https://github.com/your-username/family-collage.git
cd family-collage
# Положи все файлы сюда
git add .
git commit -m "Add family collage PWA"
git push
```

### Шаг 4️⃣: Включить GitHub Pages
1. Зайди в Settings репозитория
2. Слева найди "Pages"
3. Под "Source" выбери ветку "main"
4. Выбери папку "/" (root)
5. Нажми "Save"
6. Жди ~1-2 минуты

### Шаг 5️⃣: Получи ссылку!
После включения Pages GitHub покажет:
```
Your site is published at: https://your-username.github.io/family-collage/
```

Вот эта ссылка - копируй и отправляй Ире! 🎉

## 📱 Как открыть на телефоне/планшете

### На iOS (iPhone/iPad)
1. Открыть ссылку в Safari
2. Нажать кнопку поделиться (внизу)
3. Прокрутить вниз и нажать "На Домашний экран"
4. Нажать "Добавить"
5. Коллаж будет как приложение!

### На Android (Chrome)
1. Открыть ссылку в Chrome
2. Нажать меню (три точки сверху)
3. Нажать "Установить приложение"
4. Нажать "Установить"
5. Коллаж установится как приложение!

## 🖼 Превью ссылки в мессенджерах

В `index.html` адрес сайта прописан в тегах `og:url` и `og:image` как
`https://zios86.github.io/family-collage-redesign/`. Если репозиторий
называется по-другому — замени этот адрес в обоих тегах, иначе превью не появится.

## 🆘 Если что-то не получилось

**Ссылка не работает?**
- Подожди 5-10 минут, GitHub Pages может настраиваться
- Проверь, что в Settings → Pages выбран "main" и "/"

**Приложение не устанавливается на телефоне?**
- Открой ссылку в браузере (Chrome на Android, Safari на iOS)
- Меню → "Установить приложение"
- Если кнопки нет - значит браузер не поддерживает PWA (используй Chrome или Safari)

**Не видно фото или нет музыки?**
- Проверь, что папка `photos/` и файл `music.mp3` лежат рядом с `index.html`
- Имена файлов должны совпадать точно (с дефисами: `icon-192.png`, `service-worker.js`)
