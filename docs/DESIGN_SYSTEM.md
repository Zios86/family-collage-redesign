# Design System — Family Collage Redesign

## Арт-направление
**Тёплый семейный editorial photo album**: не набор карточек, а визуальная история с крупными фотографиями, воздухом и управляемой эмоциональной драматургией.

## Пользовательский путь
1. Подарок — человек понимает, что это персональное поздравление.
2. Открытие — одно осмысленное действие без обязательного ожидания.
3. Личное обращение — короткий эмоциональный текст.
4. История — фотографии раскрываются как последовательность воспоминаний.
5. Просмотр — любое фото можно спокойно рассмотреть в полноэкранном режиме.
6. Финал — тёплое завершение истории.

## Цветовые роли
- Фон: тёплый светлый нейтральный.
- Поверхности: молочные/бумажные оттенки.
- Основной текст: глубокий тёплый графит.
- Акцент: один приглушённый тёплый цвет для CTA и интерактивных элементов.
- Вторичный акцент: очень дозированно, только для декоративных деталей.

Конкретные HEX-значения должны применяться после извлечения фактической текущей палитры из основного HTML, чтобы не конфликтовать с существующей графикой и фотографиями.

## Типографика
- Максимум две гарнитуры.
- Выразительная гарнитура используется только для коротких заголовков и эмоциональных фраз.
- Интерфейс, подписи и навигация — нейтральная хорошо читаемая гарнитура.
- Не использовать две декоративные гарнитуры одновременно как основные.

## Пространство
Базовая шкала: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`.

## Фото
- Оригиналы не перерисовываются и не заменяются генеративно.
- Разрешены кадрирование, масштабирование, размещение и ненавязчивые CSS-эффекты вокруг изображения.
- Не все фотографии должны иметь одинаковый размер.
- Крупные кадры задают ритм, средние раскрывают историю, небольшие поддерживают композицию.

## Движение
Единый язык: короткое появление, небольшое смещение, мягкое масштабирование и понятная обратная связь.

Не использовать постоянное движение и несколько конфликтующих эффектов одновременно.

Обязательно учитывать `prefers-reduced-motion`.

## Доступность
- Сохранять заметный focus.
- Не использовать цвет как единственный индикатор.
- Интерактивные области должны быть достаточно крупными на телефоне.
- Поддерживать клавиатурную навигацию там, где она доступна.

## Адаптив
### Desktop
Свободная композиция с крупными ключевыми кадрами и большим количеством воздуха.

### Tablet
Уменьшение количества колонок, сохранение иерархии ключевых фотографий.

### Mobile
Вертикальный сценарий, крупные области нажатия, отдельная композиция вместо простого сжатия desktop-сетки.
